## Boss-card artwork

Boss-card portraits are in `assets/images/bosses/`. The final Red Square boss card is drawn dynamically on a canvas by `assets/js/game.js`.

## Hosting

This is a static project and does not require a build step. For Vercel, import the folder or repository and use the default static settings. The entry page is `index.html`.
